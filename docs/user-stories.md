# User Stories

## Qytetari

### US-01
Si qytetar dua të raportoj një problem lokal
që komuna të mund ta trajtojë.

Acceptance Criteria:
- Mund të vendos titull
- Mund të zgjedh kategori
- Mund të vendos lokacion
- Mund të ngarkoj foto


### US-02
Si qytetar dua të shoh statusin e raportit tim
që të jem i informuar për progresin.


## Zyrtari

### US-03
Si zyrtar dua të filtroj raportet
që të menaxhoj problemet sipas prioritetit.


## Administrator

### US-04
Si administrator dua të shoh statistika
që të analizoj performancën e sistemit.
