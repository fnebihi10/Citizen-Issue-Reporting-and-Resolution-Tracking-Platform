# Dizajni fillestar — jo autoritativ

Këta skedarë ruhen vetëm si histori e fazës së analizës. Disa prej tyre
paraqesin një backend të veçantë Express/NestJS dhe nuk përputhen me
implementimin final Next.js + Supabase.

Për dokumentim, prezantim dhe punim përdor vetëm diagramet SVG dhe Mermaid në
dosjen prind [`diagrams`](../../README.md).
