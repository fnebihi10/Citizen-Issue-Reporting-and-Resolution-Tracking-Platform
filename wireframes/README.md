# Wireframes for Citizen Issue Reporting Platform

Here are the responsive wireframes for the platform, covering the public view, mobile reporting form, and official dashboard.

## 1. Public Map View (Desktop)
Shows reported issues on a large map with a sidebar listing recent issues and a prominent "Report Issue" button.
![Public Map View](f:\Citizen Issue Reporting\wireframes\public_map_wireframe.png)

## 2. Issue Reporting Form (Mobile)
Mobile-first responsive form for citizens to report issues with title, description, category dropdown, location map picker, and photo upload.
![Issue Reporting Form](f:\Citizen Issue Reporting\wireframes\reporting_form_wireframe.png)

## 3. Official Dashboard (Admin Panel)
Dashboard for municipal officials and administrators to verify, assign, and track issues, featuring status filtering and SLA indicators.
![Official Dashboard](f:\Citizen Issue Reporting\wireframes\official_dashboard_wireframe.png)
